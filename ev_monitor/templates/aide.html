À quoi sert cet outil ?

Ce tableau de bord surveille la disponibilité des bornes de recharge des stations de votre choix, partout en France, à partir des données temps réel de Chargemap. Les mesures sont relevées toutes les {{ interval }} minutes et historisées.

Lire le tableau de bord

  • Vert : au moins une borne du connecteur surveillé est disponible.
  • Orange : aucune borne disponible, mais des bornes sont occupées (elles se libéreront).
  • Rouge : aucune borne disponible et rien d'occupé (station hors service ou sans données).

Pour chaque station, le tableau affiche le type de connecteur surveillé, le trajet auquel elle est rattachée, le nombre de bornes disponibles (disponibles / total), un mini-graphique des dernières 24 h, la date de la dernière indisponibilité totale et l'heure du dernier relevé. Le bouton Historique ouvre la page de détail avec les graphiques complets.

Ajouter une station

Cliquez sur Ajouter une station en haut du tableau de bord. Inutile de connaître l'identifiant (« slug ») Chargemap de la station : il est introuvable dans la barre d'adresse de Chrome, la recherche s'en charge pour vous.

  1. Recherchez la station par nom ou par ville, partout en France (ex. Vidauban, Lyon, Estérel). La liste affiche les stations trouvées avec leurs connecteurs.
  2. Cliquez sur la station souhaitée : le lien est rempli automatiquement.
  3. Choisissez le connecteur à surveiller dans le menu déroulant (Chademo, Combo CCS, Type 2…). La liste est pré-remplie avec les connecteurs réellement présents sur la station, avec leur nombre.
  4. Indiquez éventuellement le trajet auquel rattacher la station (nom libre, ex. Paris → Lyon), puis validez avec Ajouter. Saisir un nouveau nom crée le trajet.

Vous pouvez aussi ajouter une station depuis la page Carte : cliquez sur un point de la carte pour rechercher les stations Chargemap à proximité, sélectionnez-en une, choisissez le connecteur et le trajet.

Astuce : si la recherche ne trouve pas la station, essayez le nom de la commune (certaines stations sont rattachées à la ville voisine). Vous pouvez aussi coller directement l'adresse de la page Chargemap de la station dans le champ prévu à cet effet.

Trajets et préférences

La page Paramètres permet de gérer les trajets (renommer — y compris pour fusionner deux trajets — ou supprimer, ce qui détache les stations sans les effacer) et les préférences de l'application : nom, sous-titre, connecteur surveillé par défaut et intervalle de collecte. Les préférences modifiées sont prises en compte à chaud.

Questions fréquentes

Puis-je surveiller plusieurs types de connecteurs sur une même station ?

Non : un seul type de connecteur par station. Le type se choisit à l'ajout et l'historique enregistré correspond toujours à ce connecteur.

La station ajoutée affiche « Pas encore de données »

C'est normal : le premier relevé intervient au prochain cycle de collecte (au plus {{ interval }} minutes).

Une alerte rouge ou orange s'affiche en haut du tableau de bord

Le dernier cycle de collecte a rencontré des erreurs (Chargemap injoignable, station sans connecteur du type choisi…). Consultez la page Logs pour le détail.

Comment modifier ou supprimer une station ?

Le bouton Modifier du tableau de bord permet de changer le nom, l'opérateur, l'adresse, le connecteur surveillé, le trajet et l'ordre d'affichage d'une station. La liste des stations surveillées est gérée dans le fichier stations_validated.json côté serveur : contactez l'administrateur de l'instance pour supprimer une station.
